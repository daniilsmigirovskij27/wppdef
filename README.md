## 🎮 Об игре
Вы — специалист SOC (Центр мониторинга кибербезопасности). Ваша задача — отражать хакерские атаки, предотвращать физический урон турбинам и не дать уровню угрозы достигнуть 100%.

Игра сочетает в себе механику викторины, тактической RPG и мини-игр, а визуальный стиль вдохновлен корпоративными интерфейсами (в частности, UI Leningrad Games).

## 🔥 Ключевые особенности
*   **80+ уникальных атак:** от фишинга и DDoS до квантового взлома и 0-day уязвимостей.
*   **3 тактики в бою:** АТАКА (наносит урон), ЗАЩИТА (снижает входящий урон через мини-игру "Файрвол") и АНАЛИЗ (убирает неправильные варианты).
*   **5 специалистов (классов):** Аналитик, Инженер, Хакер, Диспетчер, Форензик. У каждого уникальные перки.
*   **3-фазные боссы:** с уникальными механиками, которые лечатся и блокируют ваши способности.
*   **Мета-прокачка:** Улучшение базы до 20 уровня (генераторы, защита, персонал) и глобальные навыки (Крит, Заморозка времени).
*   **Мини-игры:** Файрвол, Логическая бомба, Перехват управления, Шутер с дронами.

## 🎨 Визуальный стиль
Игра выполнена в строгом корпоративном стиле (Dark UI):
*   Тёмная графитовая палитра.
*   Фирменный оранжевый акцент.
*   Шрифты Oswald (для заголовков) и Roboto Mono (для текста).
*   Адаптивная верстка под любые экраны.

## 📦 Технологии
*   **HTML5 / CSS3 / Vanilla JavaScript (ES6+)**
*   Без сторонних фреймворков и библиотек.
*   Сохранение прогресса через `localStorage`.
*   Звуки генерируются процедурно через Web Audio API.
